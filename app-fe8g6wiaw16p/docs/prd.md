# 需求文档

## 1. 应用概述

### 1.1 应用名称
YORO

### 1.2 应用描述
YORO 是一款面向中国备考人群的成长路线图微信小程序。产品核心理念为「计划有时刻，记录无时长」，以毛玻璃视觉风格与静态景深路线图呈现，帮助用户将每天实际完成的内容转化为可视化的个人成长路线，消除备考过程中的虚无感与进度焦虑。

## 2. 用户与使用场景

### 2.1 目标用户
中国备考人群中的长期执行者，涵盖考研、考公及事业单位招考、学科竞赛、期末应试、职业资格考证等群体。

### 2.2 核心使用场景
- 制定备考主线目标与考试倒计时，通过分层路线图清晰掌握各阶段推进状态。
- 每日记录实际完成的客观成果（如刷题、复习考点），推动路线节点前进。
- 在「回声」中记录与查看个人备考日记与情绪状态，在「习惯」中点亮日常脚印，避免断签压力。
- 使用静默计时器辅助专注，计时数据不与路线图进度强制绑定。

## 3. 页面结构与功能说明

### 3.1 页面结构

- YORO 微信小程序
  - 地图主页（底部导航「地图」）
    - 倒计时卡片
    - 今日概览卡片
    - 视图切换入口（路线图视图 / 排期视图）
    - 路线图容器
    - 静默计时器插件面板
    - 首次引导浮层
    - 示例地图模式
  - 回声页（底部导航「回声」）
    - 今日日记记录
    - 历史日记时间流
  - 习惯页（底部导航「习惯」）
    - 习惯支线管理
    - 习惯打卡与脚印日历
  - 我的页（底部导航「我的」）
    - 主线管理
    - 起点模板库
    - 数据看板
    - 日历导出（.ics）
    - 系统设置
  - 业务子页面
    - 新建主线页
    - 记一笔页
    - 节点详情页

### 3.2 页面功能说明

#### 3.2.1 全局视觉与导航规范
- **全局视觉基调**：毛玻璃风格。背景采用浅天蓝到奶白的柔和渐变并叠加淡模糊光斑；禁止纯白背景与绿色系背景；不使用高饱和色彩与夸张动效，仅保留点击时轻微提亮。
- **容器卡片规范**：所有容器卡片采用半透明白底（透明度 70%~85%），配置背景高斯模糊（20px）、浅色细描边、低透明度柔和阴影与大圆角。
- **底部导航栏**：毛玻璃固定导航栏，包含「地图」「回声」「习惯」「我的」四个标签。

#### 3.2.2 地图主页
- **首屏卡片布局**：
  - **倒计时卡片**：顶部独立玻璃卡片，展示当前主线名称、目标考试日期及剩余天数倒计时；支持点击切换主线。
  - **今日概览卡片**：位于倒计时卡片下方，展示今日累计完成项、进行中支线名称与状态入口。
  - **视图切换**：提供路线图视图与排期视图切换入口，排期视图直接在地图页内切换呈现，支持按日/周查看计划时间网格。
  - **路线图容器**：单个纵向玻璃容器承载主体路线，支持纵向滑动。
- **路线图 3D 景深与视觉规则**：
  - 采用静态纵深布局，主线置于最近层平面，各科目支线按景深向后铺展，无自动旋转模型、无视差晃动。
  - 节点采用玻璃小球质感：
    - 「已走」节点：浅蓝细描边 + 淡蓝半透明填充。
    - 「在走」节点：淡粉细描边 + 轻微柔光。
    - 「未走」节点：浅灰细描边空心球体。
  - 连线：节点间使用低饱和浅灰蓝细线连接。
  - 交互反馈：点击节点仅轻微提亮与聚焦并展开详情。
- **节点文字与排版规则**：
  - 节点标签限制最大宽度，文本超出自动换行；超出最大行数以省略号截断，点击节点可展开完整文本。
  - 同一纵向支线上的相邻节点保持最小间距不小于 40 像素。
  - 支线节点过多时整条支线支持纵向滚动，禁止压缩字号或横向挤压。
- **阶段折叠与展开**：
  - 路线图按备考阶段分组，当前阶段默认展开，其余阶段默认折叠，点击阶段标题可展开或折叠。
- **首屏引导与入口**：
  - 未建主线状态：展示主色实心主按钮「写下我的终点」与描边次按钮「先随便看看示例地图」。
  - 新建主线入口：首屏右下角常驻悬浮主色实心圆按钮，点击进入新建主线页。
  - 首次进入轻引导浮层：首次打开小程序展示可跳过半透明浮层，内容聚焦「写终点去哪里」与「看地图怎么走」，点击任意处或跳过按钮即关闭。
  - 示例地图模式：进入示例地图时，顶部常驻展示「回到我的终点」返回入口。
- **图例文案与静默提示**：
  - 图例位于路线图底部，仅包含「已走」「在走」「未走」三种状态标识与对应颜色说明，去除打卡字样。
  - 容器底部固定静默文案：「每一格是你走过的路，不是连续打卡，歇几天也没关系。」。
  - 全页无排行榜、无他人进度、无连续天数、无断签提醒、无落后催促。
- **静默计时器插件**：
  - 地图页提供轻量计时入口，点击展开静默计时面板。
  - 面板顶部固定注明：「这里的时间不进地图」。
  - 支持正向与倒计时计时辅助，数据仅本地保存，不写入地图节点、看板及回声。

#### 3.2.3 回声页（今日日记）
- **日记记录**：支持输入备考心得文本、添加情绪标签（平静、有劲、低落、焦虑）与配图。
- **时间流展示**：按时间倒序展示历史记录日记卡片，仅供个人回顾，无公开或社交分享入口。

#### 3.2.4 习惯页（习惯脚印）
- **习惯支线管理**：支持新增与编辑日常习惯（如背单词、阅读等）。
- **脚印打卡与日历**：以脚印日历形式点亮完成日期，不展示连续打卡天数与补卡入口。

#### 3.2.5 我的页
- **主线管理**：展示当前主线与已归档主线列表，支持编辑与归档。
- **起点模板库**：提供预置备考路线模板供一键导入。
- **数据看板**：按周与月统计各支线已走段数与习惯脚印数，不含专注时长统计与百分比。
- **日历导出**：生成并导出包含计划时段的 .ics 标准日历文件。
- **系统设置**：基础应用偏好设置。

#### 3.2.6 记一笔页
- **顶部信息**：展示记录日期与所属主线。
- **支线选择**：展示主线下所有支线，支持单选切换。
- **完成内容输入**：提供文本输入框与预置快捷标签（过完一章、一套卷、背诵一轮、错题复盘）。
- **分量标记**：提供「主道」「便道」「旁路」三档选项，标记路线图视觉层级。
- **保存提交**：保存后对应支线新增一个「已走」节点，路线图即时更新并提示「又走了一格」。

#### 3.2.7 节点详情页
- **节点基础信息**：展示节点名称、所属支线、记录日期、计划时段与完成内容。
- **子步骤清单**：支持添加子步骤条目与勾选完成状态。
- **分量调节**：支持修改主道、便道、旁路属性。
- **状态与情绪记录**：支持记录心得、情绪标签与配图。
- **支线休整与冬眠**：
  - 休整：在当前节点生成补给站标记。
  - 冬眠：将该支线置为冬眠状态，不显示任何落后提示，支持随时激活。

#### 3.2.8 新建主线页
- **步骤一·目标与身份**：输入备考目标名称与身份。
- **步骤二·定义终点**：输入终点达成标准描述。
- **步骤三·选择模式**：支持选择模板生成或自建模式，配置考试日期与科目。
- **路线微调与确认**：生成分阶段支线节点草稿，支持调整后保存写入地图。

## 4. 业务规则与核心逻辑

### 4.1 节点状态与视觉映射规则
- **已走**：用户在记一笔或节点详情中提交完成的节点，渲染为浅蓝细描边 + 淡蓝半透明填充。
- **在走**：各支线当前推进中的最新节点，渲染为淡粉细描边 + 轻微柔光。
- **未走**：后续阶段或排期规划节点，渲染为浅灰细描边空心球体。
- **支线冬眠**：冬眠支线停止推进并保持当前状态，不作任何逾期与催促提示。

### 4.2 计划与记录分离规则
- 排期视图中的新增与调整仅作用于时间计划，不改变地图上的已走段数与节点完成状态。
- 只有在记一笔页或节点详情中提交完成记录，系统才在对应支线新增「已走」节点。
- 静默计时器数据完全独立，不向节点、地图、回声及数据看板写入任何时长记录。

## 5. 异常与边界情况

| 场景 | 边界/异常情况 | 处理规则 |
| :--- | :--- | :--- |
| 节点文字超长 | 节点名称或内容超出卡片限制宽度 | 自动换行展示，超出最大行数以省略号截断，点击节点可展开完整内容 |
| 节点数量密集 | 单支线节点过多导致垂直重叠 | 保持纵向节点间距不小于 40 像素，支线容器支持独立纵向滚动，不压缩文字字号 |
| 首屏无主线数据 | 用户首次打开小程序且无数据 | 首屏展示「写下我的终点」实心按钮与「先随便看看示例地图」描边按钮，展示轻引导浮层 |
| 示例地图返回 | 用户在示例地图模式中浏览 | 顶部常驻「回到我的终点」返回入口，点击切回真实数据或创建主线流程 |
| 支线长期未推进 | 支线多日未新增完成节点 | 维持「在走」节点状态，不触发任何断签、补卡或落后催促提醒 |

## 6. 验收标准

1. 底部导航栏正确展示「地图」「回声」「习惯」「我的」四个毛玻璃标签且切换正常。
2. 全界面应用浅天蓝至奶白渐变背景与半透明毛玻璃卡片，无纯白背景、无绿色系背景与高饱和色彩。
3. 地图页首屏仅展示倒计时卡、今日概览卡、路线图容器，支持在地图页内切换路线图与排期视图。
4. 路线图呈现静态纵深效果，节点状态严格按「已走」（浅蓝半透明）、「在走」（淡粉柔光）与「未走」（浅灰空心）渲染，连线为低饱和浅灰蓝细线，点击节点仅轻微提亮并展开详情。
5. 节点标签支持限宽换行与省略号截断，同支线节点间距不小于 40 像素，多节点支持纵向滚动且字号不压缩。
6. 未建主线时首屏展示实心主按钮「写下我的终点」与描边次按钮「先随便看看示例地图」，右下角常驻悬浮新建实心圆按钮，首次进入展示可跳过轻引导浮层。
7. 地图页底部图例去打卡化，展示静默文案「每一格是你走过的路，不是连续打卡，歇几天也没关系。」，全页无连续天数与落后提示。
8. 地图页静默计时器插件展示「这里的时间不进地图」文案，计时数据不进入地图、看板与回声，「我的」页不含计时器入口。

## 7. 本期不实现功能

- 排行榜、好友互动、他人进度展示及公开社交分享能力。
- 专注时长统计、任务完成率百分比计算。
- 强制锁机与应用使用管控功能。
- 连续打卡天数统计、断签提醒与漏打卡补签机制。
- 复杂自动旋转 3D 动画与视差晃动动效。
