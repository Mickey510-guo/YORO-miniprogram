# 需求文档

## 1. 应用概述

### 1.1 应用名称
YORO

### 1.2 应用描述
YORO 是一款面向中国备考人群的成长路线图微信小程序。产品核心理念为「计划有时刻，记录无时长」，帮助用户将每天实际做成的内容转化为可视化的个人成长路线地图，消除长期备考过程中的虚无感，专注个人积累。

## 2. 用户与使用场景

### 2.1 目标用户
中国备考人群中的长期执行者，涵盖考研、考公与事业单位、学科竞赛、期末应试、职业资格考证等群体。

### 2.2 核心使用场景
- 制定备考计划与时间排期，设定终点与考试倒计时。
- 每日记录实际完成的具体成果（如刷完一套卷子、背完一轮知识点），推动主线与支线前进。
- 查看路线图、排期网格、日记与习惯脚印，回顾个人客观积累，避免进度焦虑。

## 3. 页面结构与功能说明

### 3.1 页面结构

- YORO 微信小程序
  - 首页·地图视图
  - 排期视图
  - 新建主线页
  - 记一笔页
  - 节点详情页
  - 今日日记页
  - 习惯支线页
  - 看板页
  - 我的页
    - 起点模板库
    - 静默计时器

### 3.2 页面功能说明

#### 3.2.1 首页·地图视图
- **主线切换器**：顶部横向滑动展示多条备考主线，显示主线名称及考试日倒计时；首次使用展示「写下我的终点」与「先随便看看示例地图」两个引导入口。
- **进度文案**：展示当前主线累计天数与已走格数提示。
- **成长路线地图**：
  - 展示备考周期主线与科目支线路线图。
  - 路段形态区分：已走段为实线、未走段为虚线、冬眠支线为点线。
  - 节点形态区分：补给站为菱形、当前岔路口为粗描边圆环、主道节点大且线粗、便道节点中等且线细、旁路节点小且为虚线。
  - 节点标注完成内容文本，不标注学习时长。
  - 全页无排行榜、无他人头像、无他人进度。
- **底部工具栏**：常驻地图图例说明、视图切换入口（地图/排期切换）、右下角「今天做成了什么」快捷记一笔悬浮按钮。
- **跳转交互**：点击主线切换器切换数据；点击节点进入「节点详情页」；点击视图切换进入「排期视图」；点击记一笔按钮进入「记一笔页」。

#### 3.2.2 排期视图
- **视图切换**：支持日视图与周视图切换，展示时间网格。
- **排期节点展示**：节点以块状呈现于对应计划时段，标注计划名称与起止时间。
- **理念提示**：顶部固定文案提示「这里排的是打算什么时候走；走完了回地图记一笔，不看用了多久」。
- **时间调整交互**：
  - 支持拖动节点块修改计划日期与时段。
  - 支持拖动节点边缘调整计划时长。
  - 拖动调整仅变更计划安排，不产生节点完成记录。
- **双视图联动**：排期视图与地图视图共享相同底层节点数据，支持随时切换回地图视图。

#### 3.2.3 新建主线页
- **第一步·身份与目标**：输入身份与备考目标名称，提供引导提示语。
- **第二步·定义终点**：输入终点描述（如「什么算成功由你定」）。
- **第三步·选择起点模式**：
  - 提供「期末应试模板」与「从零自建」两张选择卡片。
  - 选择期末应试模板：必填考试日期选择器及三个科目输入框。
  - 选择从零自建：必填自定义目标名称。
- **智能路线生成与微调**：点击生成后，系统根据目标类型与剩余天数自动生成分阶段支线与带建议时段的节点；进入微调界面支持逐个新增、修改、删除节点；确认后保存并落地至首页地图。

#### 3.2.4 记一笔页
- **顶部信息**：展示当前日期。
- **支线选择**：展示当前主线下的科目支线与习惯支线列表，支持单选高亮。
- **完成内容输入**：提供自定义输入框，附带快捷标签选项（过完一章、一套卷、背诵一轮、错题复盘）。
- **分量标记**：提供「主道」、「便道」、「旁路」三档选项，仅决定后续节点在地图中的视觉粗细与样式，不触发排序或待办催促。
- **保存提交**：点击保存后，所选支线前进一格，地图即时重绘并提示「又走了一格」，支持同一天多次记录。

#### 3.2.5 节点详情页
- **基础信息展示**：展示节点名称、完成内容、所属日期、计划起止时段。
- **子步骤清单**：支持新增子步骤条目与勾选完成状态。
- **分量调节**：支持在主道、便道、旁路三档间切换更新。
- **状态与情绪记录**：提供一句话状态输入框，包含「焦虑、平静、有劲、低落」四项情绪按钮，支持添加图片与自定义标签；保存后在地图对应节点留下情绪标记。
- **岔路口操作区**：
  - 点击「休整一下」：在当前节点生成补给站菱形标记。
  - 点击「让这条支线冬眠」：将该支线置为点线冬眠态，不显示任何断签或落后提示，其他支线正常运行，支持随时重新唤醒。

#### 3.2.6 今日日记页
- **日记编辑**：提供文本输入区（支持长文本）、图片上传区（多图缩略图展示）、标签输入区。
- **保存关联**：保存后自动关联并归入当天已完成节点旁边，所有内容仅本人可见，无任何公开或分享入口。
- **历史日记列表**：按时间倒序展示历史日记条目（日期、正文、图片缩略图、标签、关联节点），点击可展开查看全文。

#### 3.2.7 习惯支线页
- **习惯列表**：展示所有习惯支线，显示习惯名称、重复规则（每日/每周）、今日完成状态、累计脚印总数。
- **打卡交互**：点击习惯打卡按钮增加一个脚印，即时刷新统计。
- **习惯日历**：展示当月日历网格，仅点亮有脚印的日期，无脚印日期留空且不作任何负面警示。
- **脚印统计**：展示本周脚印汇总数据。
- **习惯管理**：支持新建习惯支线、修改重复规则与归档习惯。
- **无挫败感设计**：全页不显示「连续天数」、「断签」、「补卡」等机制与文案。

#### 3.2.8 看板页
- **里程区（任务支线）**：按「本周」和「本月」统计各任务支线已走过的段数，并提供支线分布图表。
- **脚印区（习惯支线）**：独立统计习惯支线的累计脚印数与本周脚印数，两区域数据互不换算。
- **下钻查看**：点击指定支线可下钻查看该支线下属节点完成历史。
- **展示边界**：页面不展示任何专注时长统计与完成率百分比。

#### 3.2.9 我的页
- **主线管理**：展示主线列表（名称、考试日、剩余天数），支持主线归档操作（归档后移出首页切换器，在我的页可查）。
- **起点模板库**：展示官方备考模板（模板名称、适用考试、周期长度），支持一键导入；无点赞、无排行、无评论、无作者信息。
- **静默计时器**：提供免打扰计时工具，页面显著提示「这里的时间不会进地图，也不会进看板」，计时结束后提供一键返回地图记一笔入口。
- **导出到日历**：生成并导出标准 .ics 日历文件，计划节点包含起止时刻，考试日生成全天日程。
- **系统设置与状态**：显示当前皮肤（如「纸地图·墨绿」）、示例地图入口、微信授权轻登录状态。

## 4. 业务规则与核心逻辑

### 4.1 核心数据结构与关系
- **主线**：包含名称、品类、考试日期、终点描述、归档状态。
- **支线**：归属于主线，包含名称、类型（科目支线/习惯支线）、状态（正常/冬眠/归档）、最后记录时间。
- **节点**：归属于支线，包含名称、类型、计划日期、计划起止时刻、完成日期、完成内容、状态（已完成/计划中/补给站）、分量（主道/便道/旁路）。
- **日记**：归属于日期与节点，包含日期、文本内容、图片列表、标签、情绪类型（焦虑/平静/有劲/低落）。
- **脚印**：归属于习惯支线，记录打卡日期。

### 4.2 计划与记录分离规则
- 用户在排期视图规划节点时，仅生成计划起止时刻，不改变地图上的已走段数与节点完成状态。
- 只有在记一笔页或节点中提交「完成内容」时，系统才在对应支线增加完成节点并点亮实线路线。
- 静默计时器仅提供时间辅助，不统计时长，不向节点、地图或看板写入任何时长数据。

### 4.3 节点视觉映射规则
- 分量标记映射：主道对应大尺寸节点与粗实线；便道对应中尺寸节点与细实线；旁路对应小尺寸节点与虚线。
- 状态映射：冬眠支线统一渲染为点线；标记休整的节点渲染为菱形补给站。

### 4.4 预置初始化数据
- **主线 1（考研）**：终点 2027-12-20；下设数学（已走 12 段）、英语（已走 7 段，含 1 个补给站及 1 个当前岔路口节点）、专业课（冬眠状态）。
- **主线 2（蓝桥杯）**：终点 2027-04-11；下设算法（已走 3 段）、数据结构（已走 2 段）。
- **预置排期数据**：本周三 15:00-17:00 复习数学；周四 09:00-10:30 英语阅读；周五 14:00-16:00 算法专题。
- **预置习惯支线**：每日背单词（累计 43 个脚印）；运动（累计 12 个脚印，规则每周三次）。
- **预置日记数据**：包含 3 条历史日记（「背了三遍还是记不住」配图与英语标签、「今天状态不错，一章顺下来了」、「有点慌，进度比想象慢」）。

## 5. 异常与边界情况

| 场景 | 边界/异常情况 | 处理规则 |
| :--- | :--- | :--- |
| 新建主线表单提交 | 必填项缺失（如科目未填满3个或考试日期未选） | 阻止提交并在对应输入框下方高亮提示必填项 |
| 空数据状态 | 新建主线无节点、习惯列表无习惯、日记列表为空 | 显示专属引导插画与「添加第一条记录」引导文案 |
| 支线冬眠 | 支线长期未记录 | 保持点线状态，严禁弹出「已断签」、「落后进度」等负面提示 |
| 日历导出失败 | 本地权限受阻或生成中断 | 弹出重试提示并保留生成内容 |
| 排期时段冲突 | 同一时间段排入多个节点 | 允许并列排期，不弹冲突阻断提示 |

## 6. 验收标准

1. 用户在首页可通过主线切换器在「考研」与「蓝桥杯」之间平滑切换，倒计时与路线图数据同步更新。
2. 用户点击「今天做成了什么」进入记一笔页，选择支线、输入完成内容、选择分量标记并保存后，返回首页可立即看到该支线前进一格实线节点。
3. 用户在地图视图与排期视图之间切换时，各节点的计划时段与完成状态严格保持一致，且在排期视图中拖拽调整时段不产生完成节点。
4. 用户进入节点详情页，可成功更新子步骤、修改情绪状态，并可执行「休整一下」生成菱形补给站或「让这条支线冬眠」使支线变为点线。
5. 用户在习惯支线页完成打卡后，累计脚印数即时加 1，日历对应日期亮起，且页面无任何连续天数或断签提醒。
6. 用户在新建主线页完成三步表单填写并生成路线后，经微调保存可完整落入首页地图。
7. 用户在我的页可正常使用静默计时器，计时结束后返回地图，看板与地图中均不出现任何计时时长统计。
8. 用户在我的页点击导出日历，可成功下载包含计划起止时刻的 .ics 日历文件。

## 7. 本期不实现功能

- 排行榜、好友互动、他人进度展示及社交分享功能。
- 专注时长累计统计、任务完成率百分比计算。
- 手机端应用白名单管控与强制锁机专注功能。
- 连续打卡天数统计、断签提醒、漏打卡补签机制。
- 课程内容分发、付费商城及日历双向回读同步功能。
