# 需求文档

## 1. 应用概述

### 1.1 应用名称
YORO

### 1.2 应用描述
YORO 是一款面向中国备考人群的成长路线图微信小程序。产品核心理念为「计划有时刻，记录无时长」，以毛玻璃视觉风格与克制的静态景深路线图呈现，帮助用户将每天实际完成的内容转化为可视化的个人成长路线，消除长期备考过程中的虚无感与焦虑。

## 2. 用户与使用场景

### 2.1 目标用户
中国备考人群中的长期执行者，涵盖考研、考公与事业单位、学科竞赛、期末应试、职业资格考证等群体。

### 2.2 核心使用场景
- 制定备考主线目标与考试倒计时，通过分层路线图清晰掌握各阶段推进状态。
- 每日记录实际完成的客观成果（如做完一套卷子、复习完一轮考点），推动主线与支线前进。
- 查看路线图、排期、日记与习惯脚印，回顾个人客观积累，避免断签压力与进度焦虑。

## 3. 页面结构与功能说明

### 3.1 页面结构

- YORO 微信小程序
  - 地图主页（底部导航「地图」）
    - 倒计时卡片
    - 今日概览卡片
    - 路线图容器
    - 首次引导浮层
    - 示例地图模式
  - 我的页（底部导航「我的」）
    - 主线管理
    - 排期日历
    - 今日日记（回声）
    - 习惯脚印
    - 数据看板
    - 起点模板库
    - 静默计时器
  - 业务功能页/子页面
    - 新建主线页
    - 记一笔页
    - 节点详情页

### 3.2 页面功能说明

#### 3.2.1 全局视觉与导航规范
- **全局视觉基调**：毛玻璃（Glassmorphism）风格。背景采用浅天蓝到奶白的柔和渐变并叠加淡模糊光斑；禁止使用纯白背景与绿色系背景；不使用高饱和色彩与夸张动效，仅保留点击时轻微提亮。
- **容器卡片规范**：所有容器卡片采用半透明白底（透明度 70%~85%），配置背景高斯模糊（20px）、浅色细描边、低透明度柔和阴影与大圆角。
- **底部导航栏**：毛玻璃底部固定导航栏，仅包含「地图」和「我的」两个标签。

#### 3.2.2 地图主页
- **首屏卡片布局**：
  - **倒计时卡片**：顶部独立玻璃卡片，展示当前主线名称、目标考试日期及剩余天数倒计时；支持点击切换主线。
  - **今日概览卡片**：位于倒计时卡下方，展示今日累计记录完成项、正在进行的支线名称与状态入口。
  - **路线图容器**：合并为单个纵向玻璃容器承载主体路线，支持纵向滑动。
- **路线图视觉与 3D 景深**：
  - 采用静态视角景深布局，主线置于最近层平面，各科目支线按景深向后铺展，无自动旋转模型、无视差晃动。
  - 节点采用玻璃小球质感：
    - 「已走」节点：浅蓝细描边 + 淡蓝半透明填充。
    - 「在走」节点：淡粉细描边 + 轻微柔光效果。
    - 「未走」节点：浅灰细描边空心球体。
  - 连线：节点间使用低饱和浅灰蓝细线连接。
  - 交互反馈：仅保留点击节点时的轻微提亮或聚焦效果。
- **节点文字与排版规则**：
  - 节点标签限制最大宽度，文本超出自动换行；超过最大行数以省略号截断，点击节点可展开完整文本。
  - 同一纵向支线上的相邻节点保持最小间距不小于 40 像素。
  - 支线节点较多时支持单条支线纵向滚动，禁止压缩字号或横向挤压。
- **阶段折叠与展开**：
  - 路线图按备考阶段分组，当前正在进行的阶段默认展开展示，其余历史或未来阶段默认折叠，点击阶段标题可手动展开/收起。
- **首屏引导与入口**：
  - 未建主线状态：展示「写下我的终点」（主色实心填充主按钮）与「先随便看看示例地图」（浅色描边次按钮）。
  - 新建主线入口：首屏右下角常驻悬浮主色实心圆按钮，点击进入新建主线页。
  - 首次进入轻引导浮层：首次打开小程序展示半透明可跳过浮层，文案聚焦「写终点去哪里」与「看地图怎么走」，点击任意处或跳过按钮即关闭。
  - 示例地图模式：进入示例地图时，顶部常驻展示「回到我的终点」返回入口，点击即切回用户真实数据或创建页。
- **图例文案与静默提示**：
  - 图例位于路线图底部，仅包含「已走」「在走」「未走」三种状态标识与对应颜色说明，无任何打卡字样。
  - 容器底部固定静默文案：「每一格是你走过的路，不是连续打卡，歇几天也没关系。」。
  - 全页无排行榜、无他人进度、无连续天数、无断签提醒、无落后催促。

#### 3.2.3 记一笔页
- **顶部信息**：展示当前记录日期与所属主线。
- **支线选择**：展示当前主线下的所有支线，支持单选高亮。
- **完成内容输入**：提供文本输入框与预置快捷标签（如过完一章、一套卷、背诵一轮、错题复盘）。
- **分量标记**：提供「主道」、「便道」、「旁路」三档选项，用于标记节点在路线图上的视觉层级与连线粗细，不触发排序或催促。
- **保存提交**：点击保存后所选支线新增一个「已走」节点，路线图即时更新并提示「又走了一格」。

#### 3.2.4 节点详情页
- **节点信息**：展示节点名称、所属支线、记录日期、计划起止时段与完成内容。
- **子步骤清单**：支持添加子步骤条目与勾选完成状态。
- **分量调节**：支持修改主道、便道、旁路属性。
- **状态与情绪记录**：提供一句话心得输入框、情绪选项（焦虑、平静、有劲、低落）及图片添加能力，保存后同步在路线图节点留下状态标记。
- **支线休整与冬眠**：
  - 点击「休整一下」：在当前节点生成补给站标记。
  - 点击「让这条支线冬眠」：将该支线置为冬眠状态，不显示任何落后或催促提示，支持后续随时重新激活。

#### 3.2.5 新建主线页
- **步骤一·目标与身份**：输入备考目标名称及身份。
- **步骤二·定义终点**：输入终点达成标准描述。
- **步骤三·选择模式**：
  - 模板生成模式：选择预置备考模板，选择考试日期及科目。
  - 自建模式：输入自定义科目与周期。
- **路线微调与确认**：自动生成分阶段支线节点草稿，支持手动增删改节点，点击保存后写入地图。

#### 3.2.6 我的页及收敛子模块
- **主线管理**：展示当前主线与已归档主线列表，支持主线编辑与归档。
- **排期日历（次级入口）**：支持日视图与周视图时间网格，支持拖动调整计划起止时段，调整仅改变排期安排，不自动生成完成节点。
- **今日日记 / 回声（次级入口）**：按时间倒序展示历史记录日记（含文字、配图、关联节点与情绪），无公开与社交分享入口。
- **习惯脚印（次级入口）**：管理习惯支线并进行打卡记录，以脚印日历展示点亮日期，不展示连续打卡天数与补卡入口。
- **数据看板（次级入口）**：按周和月统计各支线已走段数及习惯脚印数，不包含专注时长与完成率百分比。
- **起点模板库**：提供官方备考路线模板供一键导入。
- **静默计时器**：免打扰正向/倒计时辅助工具，标注「这里的时间不会进地图，也不会进看板」，计时结束后提供返回地图记一笔入口。
- **日历导出**：生成并导出包含计划时段的 .ics 标准日历文件。

## 4. 业务规则与核心逻辑

### 4.1 节点状态与视觉对应规则
- **已走（已完成）**：用户在记一笔或详情中提交完成的节点，渲染为浅蓝细描边加淡蓝透明填充。
- **在走（进行中）**：各支线当前所处最新推进中的节点，渲染为淡粉细描边加轻微柔光。
- **未走（计划中）**：后续阶段或未到达的排期节点，渲染为浅灰细描边空心球体。
- **支线冬眠**：冬眠支线停止推进，保持原样，不作任何落后警示。

### 4.2 计划与记录分离规则
- 在排期日历中新增或调整节点仅生成时间计划，不改变地图上的已走段数与节点完成状态。
- 只有在记一笔页或节点中提交「完成内容」时，系统才在对应支线新增「已走」节点并推进路线。
- 静默计时器不向节点、地图或看板写入任何时长数据。

### 4.3 预置初始化数据
- **主线 1（考研）**：终点 2027-12-20；下设数学（12 个已走节点）、英语（7 个已走节点，含 1 个补给站及 1 个在走节点）、专业课（冬眠状态）。
- **主线 2（蓝桥杯）**：终点 2027-04-11；下设算法（3 个已走节点）、数据结构（2 个已走节点）。
- **预置排期**：本周三 15:00-17:00 数学；周四 09:00-10:30 英语；周五 14:00-16:00 算法。
- **预置习惯**：背单词（累计 43 个脚印）、运动（累计 12 个脚印）。
- **预置日记**：包含 3 条历史记录文本及情绪标签。

## 5. 异常与边界情况

| 场景 | 边界/异常情况 | 处理规则 |
| :--- | :--- | :--- |
| 节点文本过长 | 节点名称或完成内容超出最大宽度限制 | 自动换行截断并展示省略号，点击节点后弹出完整详情 |
| 节点密度过高 | 单条支线节点数量过多导致纵向堆叠 | 保持节点间距不小于 40 像素，支线容器支持独立纵向滚动 |
| 首次进入无数据 | 用户未创建任何主线 | 首屏展示写下终点主按钮与看示例地图次按钮，并弹出轻引导浮层 |
| 示例地图退出 | 用户在示例地图中浏览后需要返回 | 点击顶部「回到我的终点」即退出示例模式并返回主界面 |
| 支线长期未记录 | 某科目支线数日未新增完成节点 | 保持当前在走节点状态，不触发任何断签、逾期或落后提醒 |

## 6. 验收标准

1. 地图主页首屏仅展示倒计时卡片、今日概览卡片及单个纵向毛玻璃路线图容器，底部导航仅包含「地图」和「我的」两个标签。
2. 全界面应用浅天蓝至奶白渐变背景与半透明白底毛玻璃卡片，且无任何纯白底、绿色系背景及高饱和色彩。
3. 路线图呈现静态 3D 景深分层，主线在最前、支线在后，节点样式准确映射「已走」（浅蓝半透明）、「在走」（淡粉柔光）与「未走」（浅灰空心），连线为低饱和浅灰蓝细线，点击节点仅轻微提亮。
4. 节点标签宽度受限且换行截断正常，单支线节点间距不小于 40 像素，多节点时支持纵向滚动且字号无压缩。
5. 路线图默认仅展开当前阶段，图例与底部文案去打卡化，展示「每一格是你走过的路，不是连续打卡，歇几天也没关系。」且无连续天数提示。
6. 未建主线时首屏提供实心主按钮「写下我的终点」与描边次按钮「先随便看看示例地图」，右下角常驻悬浮新建实心圆按钮，首次进入正常展示轻引导浮层。
7. 排期日历、今日日记、习惯脚印及数据看板均收敛在「我的」或二级入口中，不在首屏平铺。
8. 在记一笔页保存完成记录后，对应支线实时新增一个已走节点，排期与静默计时器均不向地图写入时长数据。

## 7. 本期不实现功能

- 排行榜、好友互动、他人进度展示及社交分享功能。
- 专注时长统计、任务完成率百分比计算。
- 手机端应用白名单管控与强制锁机专注功能。
- 连续打卡天数统计、断签提醒、漏打卡补签机制。
- 自动旋转 3D 复杂模型与视差晃动动画。
- 课程付费商城及日历双向回读同步功能。
